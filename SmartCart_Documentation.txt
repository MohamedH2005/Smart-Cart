الأدوار المتاحة:
-----------------
1. Admin - صلاحيات كاملة على جميع الوحدات
2. Manager - جميع الصلاحيات عدا Admin
3. Marketing - Sales, Reports, Marketing
4. User - Sales, Profile فقط
5. Supervisor - Inventory, Sales, Customers, Reports, Profile
6. Cashier - Sales, Profile فقط
7. Inventory Manager - Inventory, Profile فقط
8. HR Manager - Admin, Profile فقط
9. Accountant - Reports, Profile فقط

التحكم بالصلاحيات:
--------------------
- يتم التحقق من صلاحيات المستخدم قبل الوصول لأي وحدة
- يتم عرض رسالة خطأ في حالة عدم وجود صلاحية
- يتم تنفيذ الـ checks في HomePanel و Dashboard

================================================================================
                            نظام الملفات
================================================================================

الملفات المستخدمة:
-------------------
1. users.txt - تخزين بيانات المستخدمين (username,password,role)
2. products.txt - تخزين بيانات المنتجات
3. customers.txt - تخزين بيانات العملاء
4. sales.txt - تخزين سجلات المبيعات (orderId,total,date)
5. logs.txt - تخزين سجلات النظام مع الطابع الزمني

عمليات الملفات:
----------------
- الحفظ: يتم عند أي إضافة/تحديث/حذف
- التحميل: يتم عند بدء التشغيل
- Append: للمبيعات والسجلات (للحفاظ على التاريخ)
- معالجة الأخطاء: جميع عمليات الملفات محمية بـ try-catch

================================================================================
                            الأمان
================================================================================

تشفير كلمات المرور:
--------------------
- يتم استخدام SHA-256 لتشفير كلمات المرور
- لا يتم تخزين كلمات المرور بصيغة نصية
- يتم التحقق من خلال مقارنة الـ hash

التحقق:
-------
- التحقق من البيانات الفارغة قبل المعالجة
- التحقق من وجود المستخدم قبل العمليات
- معالجة جميع الاستثناءات

================================================================================
                            الخلاصة
================================================================================

نظام SmartCart Hyper Market System هو نظام متكامل لإدارة السوبرماركت يتضمن:

1. نظام مصادقة متعدد الأدوار مع تشفير كلمات المرور
2. إدارة كاملة للمخزون (إضافة، تحديث، حذف، بحث)
3. نظام مبيعات مع سلة تسوق ومعالجة الطلبات
4. إدارة علاقات العملاء
5. إدارة المستخدمين والصلاحيات
6. وحدة تسويق مع إنشاء العروض
7. نظام تقارير شامل
8. ملف شخصي للمستخدم مع سجل الأنشطة
9. تخزين البيانات في ملفات نصية
10. تصميم حديث وموحد

التقنيات المستخدمة:
-------------------
- Java Swing للواجهة الرسومية
- HashMap لتخزين البيانات في الذاكرة
- File I/O للتخزين الدائم
- SHA-256 لتشفير كلمات المرور
- CardLayout للتنقل بين الصفحات
- Role-Based Access Control للصلاحيات
